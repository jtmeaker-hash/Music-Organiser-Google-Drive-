Implement a secure first-run credential setup wizard to replace Google Colab's userdata secrets system.

Support the existing secret names:
- SONOVAULT_API_KEY
- AUDIOMETA_API_KEY
- DISCOGS_TOKEN

Store credentials in ~/.config/musicvault/.env with restrictive file permissions (0600). Support environment variable overrides and allow individual credentials to be updated through the settings menu.

Mask credential entry, validate provider connectivity and never print actual secrets in logs or reports.

Implement persistent Google OAuth authentication compatible with Termux, replacing google.colab.auth.

Exclude all credential files, OAuth tokens and private configuration from Git version control. Provide a placeholder-only .env.example file.

Preserve credentials across application updates and allow optional providers to be skipped without crashing the application.

Do not request actual secrets in the agent chat or embed them in source code. The user will enter them locally on first launch. Use a supported Google OAuth flow; do not use deprecated out-of-band authentication. Test on Android before claiming compatibility.
